DiaFitus — reviewer photos
==========================

To replace the auto-generated SVG avatar on a review with a real photo,
drop a file named after the reviewer (lowercased, spaces -> dashes,
dots removed) in this folder.

  Example:  reviewer name "Marcus T." -> assets/reviews/marcus-t.jpg
            reviewer name "Lena R."   -> assets/reviews/lena-r.png

 - Accepted: .jpg .jpeg .png .webp
 - Recommended: square 200x200, under 80 KB
 - If a file is missing, the cartoon SVG avatar is shown instead.
