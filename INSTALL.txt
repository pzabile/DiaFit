============================================================
 DiaFitus — Hostinger setup guide
 Operated by Benux Corp
============================================================

This document walks you through the exact steps to take a fresh
Hostinger account from zero to a working DiaFitus install with:

 - public marketing site, questionnaire, offer page, signup, login
 - Stripe subscription checkout ($80 list / $40 with 50% off)
 - MySQL database for leads, members, weekly notes, daily logs,
   meal photos, coach notes and admin notes
 - Member dashboard at /dashboard
 - Admin backend at /admin
 - Telegram notifications + welcome emails on every paid signup

Estimated setup time: ~30 minutes.

------------------------------------------------------------
 1. DOMAIN AND PHP
------------------------------------------------------------

 1.1  In Hostinger hPanel, point your domain (diafitus.com) to
      the hosting plan. Wait for DNS to resolve.

 1.2  hPanel -> Websites -> diafitus.com -> Advanced -> PHP
      Configuration:
        - PHP version: 8.1 or higher (8.2 recommended)
        - Required extensions (all on by default on Hostinger):
          mysqli, pdo_mysql, curl, gd OR imagick, fileinfo,
          openssl, mbstring, json
        - Set max_upload_size to at least 10M
        - Set post_max_size to at least 12M

 1.3  hPanel -> Websites -> Force HTTPS = ON, and install the
      free SSL certificate from the SSL panel.

------------------------------------------------------------

------------------------------------------------------------
 3. CREATE THE DATABASE
------------------------------------------------------------

 3.1  hPanel -> Databases -> MySQL Databases.
      Click "Create new database":
        - Database name:    diafitus
        - Database user:    diafitus
        - Password:         (generate strong, copy it now)
      Save the database name, user and password. Hostinger
      prefixes them with your account id (e.g. u123_diafitus).

 3.2  Click "Enter phpMyAdmin" next to the new database.
      In phpMyAdmin select the database from the left sidebar,
      then click the SQL tab, paste the entire contents of
      schema.sql, and click Go.

      You should see "MySQL returned an empty result set" for
      each table, plus the admin user inserted.

 3.3  The schema seeds a default admin user:
        username: admin
        password: DiaFitusAdmin#2026

      ROTATE THIS IMMEDIATELY. Generate a new hash by running
      this command on any PHP host (or in a sandbox like
      https://www.php8.dev/online-editor):

        php -r "echo password_hash('your-new-strong-password',
                 PASSWORD_BCRYPT);"

      Then in phpMyAdmin run:
        UPDATE admins
        SET password_hash = '$2y$12$...your_new_hash_here...'
        WHERE username = 'admin';

------------------------------------------------------------
 4. EDIT config.php
------------------------------------------------------------

 Open public_html/config.php in File Manager and update:

  - db.name, db.user, db.pass  -> the values from step 3.1
  - db.host                    -> leave as 'localhost'
  - site_url and dashboard_url -> https://diafitus.com (etc.)
  - mail.from_email            -> a real address on your domain
                                  (create it under hPanel -> Emails)
  - support_email              -> support@diafitus.com (created
                                  under hPanel -> Emails)

 Stripe and Telegram are covered in the next steps.

------------------------------------------------------------
 5. STRIPE
------------------------------------------------------------

 5.1  Create a Stripe account at https://stripe.com if you don't
      have one. Complete the business verification using
      Benux Corp's details.

 5.2  Stripe Dashboard -> Developers -> API keys.
      Copy:
        - Publishable key (pk_live_...)
        - Secret key      (sk_live_...)
      Paste them into config.php under 'stripe'.

      For testing first, use pk_test_... / sk_test_... and a test
      card 4242 4242 4242 4242, any future date, any CVC.

 5.3  Stripe Dashboard -> Developers -> Webhooks ->
      "Add endpoint":
        URL:                 https://diafitus.com/webhook
        Listen to:           Events on your account
        Events:              checkout.session.completed
                             customer.subscription.deleted (optional)
      Save. Then click the new endpoint, copy the "Signing
      secret" (whsec_...) and paste into config.php under
      stripe.webhook_secret.

 5.4  In Stripe Dashboard -> Settings -> Customer emails,
      enable email receipts so Stripe also sends a payment
      receipt to the customer.

 6. TELEGRAM
------------------------------------------------------------

 6.1  The bot token and chat id are already wired in
      config.php (you supplied them):

        bot_token = 8656432898:AAHZo5Iv6apbauNaLcyGgUIlP_7P_aP9qXg
        chat_id   = 325385972

      You will receive:
        - every assessment submission (text + PDF)
        - every paid signup (text + PDF)

 6.2  IMPORTANT: open Telegram and message your own bot once,
      OR add the bot to a private channel where you are an
      admin. A bot can only send messages to chats it has been
      added to or has been started with /start.

      To start the bot: in Telegram search "@YourBotUsername",
      open it, tap Start, send "hi". This unlocks the chat.

 6.3  Create the public Telegram handle members use for 24/7
      support, e.g. @DiaFitusSupport. Update in config.php:
        telegram.member_link = 'https://t.me/YourHandle'

      Members will see this link on their dashboard. They click
      it to start chatting with you on Telegram. We do not
      mention Telegram anywhere in marketing copy except the
      FAQ and the Privacy Policy.

 6.4  SECURITY: the bot token sitting in config.php gives
      anyone full control of the bot. config.php is protected
      from web access by .htaccess, but you should still:
        - never commit config.php to a public git repository
        - rotate the bot token from @BotFather if it leaks

------------------------------------------------------------
 7. EMAIL (welcome email after purchase)
------------------------------------------------------------

 7.1  hPanel -> Emails -> Email Accounts -> Create:
        no-reply@diafitus.com
        support@diafitus.com

 7.2  hPanel -> Emails -> DNS Records -> set up SPF, DKIM and
      DMARC for diafitus.com. This is required so Gmail/Outlook
      don't reject welcome emails. Hostinger has a 1-click
      button for this.

 7.3  The welcome email is sent automatically via PHP mail()
      using no-reply@diafitus.com. Test by completing a Stripe
      test purchase end-to-end.

      If welcome emails don't arrive: check Hostinger
      hPanel -> Emails -> Mail logs and confirm SPF/DKIM are
      passing.

------------------------------------------------------------

 8.1  Visit https://diafitus.com — landing page should load.

 8.2  Click "Start now" -> walk through the questionnaire ->
      submit. Your Telegram should ping immediately with a
      text summary + a PDF attachment.

 8.3  On the offer page click "Claim 50% off" -> fill the form ->
      Stripe checkout. Pay with the test card 4242... in test
      mode, or for real in live mode.

 8.4  You'll land on /success, see your one-time password
      (also emailed), and then be able to log in at /login.

 8.5  Go to /admin/login, sign in with admin / your new
      password, and you'll see:
        - Overview (KPIs: leads, members, MRR, etc.)
        - Leads (assessments with no payment) at /admin/leads
        - Members (paid) at /admin/members
        - Member detail at /admin/member?id=...
          where you can view all questionnaire answers,
          upload the personalized program PDF, leave coach
          notes that the member sees in their dashboard, and
          private admin-only notes.

------------------------------------------------------------
 10. SECURITY NOTES
------------------------------------------------------------

 - All passwords are stored using bcrypt (password_hash).
 - All database access uses PDO prepared statements — no
   string concatenation in SQL.
 - CSRF tokens protect every state-changing form.
 - Sessions regenerate id on login.
 - Uploaded images are validated by MIME type AND extension
   is whitelisted by us, never trusted from client.
 - The uploads folder has its own .htaccess that denies
   execution of .php files, so even if an attacker uploaded
   a PHP-disguised image it would not be executed.
 - config.php and includes/ are denied direct web access.
 - Webhook signatures are verified using HMAC-SHA256 before
   trusting the payload.
 - The X-Frame-Options and Referrer-Policy headers are set.

 Things you should still do:
  - Enable 2FA on Stripe, Hostinger and the Telegram account
    associated with the bot.
  - Take a weekly backup of the MySQL database from hPanel.
  - Rotate the bot token if it leaks anywhere public.
